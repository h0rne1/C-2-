## Задание

Класс `GameInventory` хранит фиксированное количество слотов, каждый из которых может содержать название предмета или быть пустым.

1. Конструктор `GameInventory(int slotsCount)` — создаёт инвентарь с заданным количеством пустых слотов.
2. Индексатор `this[int slot]` — доступен на чтение и запись, возвращает/задаёт название предмета в указанном слоте. Бросает `ArgumentOutOfRangeException`, если номер слота вне диапазона.
3. Индексатор `this[string itemName]` — только на чтение, возвращает количество слотов, в которых лежит предмет с этим названием.
4. Переопределить `ToString()`, чтобы вывести содержимое всех слотов, например: `"[Меч, -, Зелье, -, -]"`.

**Ограничение:** задача решена именно двумя отдельными перегруженными индексаторами — не одним индексатором с необязательным параметром и не методами `GetByPosition`/`GetByName` вместо `this[...]`.

## Описание реализации

Реализация находится в файле [`GameInventory.cs`](./GameInventory.cs).

- `this[int slot]` — чтение/запись, проверка границ диапазона.
- `this[string itemName]` — только чтение, подсчёт совпадений по названию.
- `ToString()` — выводит слоты через запятую в квадратных скобках, пустые слоты как `-`.
- Класс `Program.Main` демонстрирует работу обоих индексаторов и обработку исключения.
