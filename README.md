# GameInventory

Класс `GameInventory` реализует простой инвентарь с фиксированным количеством
слотов. Каждый слот либо пуст, либо содержит название предмета.

## Состав

### Конструктор
```csharp
GameInventory(int slotsCount)
```
Создаёт инвентарь с заданным числом пустых слотов. Если `slotsCount`
отрицательный — бросает `ArgumentOutOfRangeException`.

### Индексатор по номеру слота
```csharp
string this[int slot] { get; set; }
```
Доступен на чтение и запись. Возвращает или задаёт название предмета
в указанном слоте. Если `slot` выходит за границы диапазона (меньше 0 или
больше либо равен количеству слотов) — бросает `ArgumentOutOfRangeException`.

### Индексатор по названию предмета
```csharp
int this[string itemName] { get; }
```
Только на чтение. Возвращает количество слотов, в которых лежит предмет
с указанным названием.

> Оба индексатора — это **две отдельные перегрузки** `this[...]` (по `int`
> и по `string`), а не один индексатор с необязательным параметром и не
> обычные методы вроде `GetByPosition` / `GetByName`. Именно перегрузка
> индексаторов — то, что тренирует эта задача.

### ToString()
Переопределённый метод выводит содержимое всех слотов в формате:
```
[Меч, -, Зелье, -, -]
```
Пустые слоты отображаются как `-`.

## Точка входа

Для запуска как самостоятельной программы добавлен класс `Program` с методом
`Main`, который демонстрирует работу обоих индексаторов, `ToString()` и
обработку `ArgumentOutOfRangeException`.

> Важно: во всём проекте должен быть только один метод `Main`. Если в
> проекте уже есть другой файл с `Main`, удалите лишний — иначе компилятор
> выдаст ошибку о нескольких точках входа.

## Пример использования

```csharp
var inventory = new GameInventory(5);
inventory[0] = "Меч";
inventory[2] = "Зелье";

Console.WriteLine(inventory);          // [Меч, -, Зелье, -, -]
Console.WriteLine(inventory[0]);       // Меч
Console.WriteLine(inventory["Зелье"]); // 1
Console.WriteLine(inventory["Щит"]);   // 0

// inventory[10] = "X"; // бросит ArgumentOutOfRangeException
```

## Ожидаемый вывод при запуске

```
[Меч, -, Зелье, -, -]
Меч
1
0
Ошибка: Номер слота вне диапазона.
Parameter name: slot
```

## Файлы

- `GameInventory.cs` — реализация класса и метод `Main` для запуска.

## Ограничения / критерии

- Ровно два перегруженных индексатора: `this[int]` (чтение/запись) и
  `this[string]` (только чтение).
- Некорректный номер слота в `this[int]` бросает `ArgumentOutOfRangeException`.
- `ToString()` выводит все слоты через запятую в квадратных скобках,
  пустые слоты — как `-`.
